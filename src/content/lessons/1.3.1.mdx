## Big idea

A **literal** is a value you write directly in your code, exactly as it is: a number like `12`, a piece of text like `"hello"`, or `True`. Python looks at **how** a literal is written to decide what **type** of data it is. The type decides what you can do with the value.

```python
print(type(12))
print(type(12.0))
print(type("12"))
print(type(True))
```

```output
<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
```

`type()` is a built-in function that tells you the type of a value. These four look similar, but they are four different types:

| Literal | Type | Meaning |
|---|---|---|
| `12` | `int` | a whole number (integer) |
| `12.0` | `float` | a number with a decimal point |
| `"12"` | `str` | text (a string of characters) |
| `True` | `bool` | a yes/no value (Boolean) |

## Walkthrough

### The four basic types

The rule is all in the writing:

- No decimal point and no quotes: an **int**, such as `0`, `42` or `-7`.
- A decimal point: a **float**, such as `3.5`, `-0.25` or `2.0`.
- Quotes around it: a **str**, such as `"pizza"` or `'42'`. Anything in quotes is text, even if it looks like a number.
- The exact words `True` or `False`: a **bool**.

Types matter because they behave differently. `+` adds numbers, but it joins strings:

```python
print(2 + 3)
print("2" + "3")
print(2.0 + 3)
```

```output
5
23
5.0
```

Mixing an int with a float gives a float, which is why the last line shows `5.0`.

### Boolean literals

A **Boolean** value is either `True` or `False`, nothing else. Booleans answer yes/no questions, such as "is the shop open?". Comparisons like `>` produce them too:

```python
shop_open = True
raining = False
print(shop_open, raining)
print(5 > 3, type(5 > 3))
```

```output
True False
True <class 'bool'>
```

They must be written with a capital first letter and no quotes. `"True"` in quotes is a string, not a Boolean, and `true` in lower case is not a literal at all:

```python
answer = true
```

```error
NameError: name 'true' is not defined
```

### Integer and float literals

**Integers** are whole numbers, positive, negative or zero. Python ints can be as big as you like:

```python
apples = 12
temperature = -4
stars = 2 ** 70
print(apples, temperature, stars)
```

```output
12 -4 1180591620717411303424
```

A **float** is any number written with a decimal point. A point on its own is enough, even with nothing on one side of it:

```python
print(4.5, 4.0, 4., .5)
print(type(4.), type(4))
```

```output
4.5 4.0 4.0 0.5
<class 'float'> <class 'int'>
```

So `4` and `4.0` have the same value but different types. Dividing with `/` always gives a float, even when the result is whole:

```python
print(10 / 2)
print(7 / 2)
```

```output
5.0
3.5
```

Don't put commas in a number to group thousands. Python reads a comma as "two separate values":

```python
price = 1,500
print(price)
```

```output
(1, 500)
```

### The limits of floats

A computer stores floats in binary (with 0s and 1s), using a fixed amount of memory. Most decimal fractions, such as 0.1, can't be stored **exactly** that way, just as 1/3 can't be written exactly in decimal (0.3333...). So Python stores the closest value it can, and tiny errors can show up:

```python
print(0.1 + 0.2)
print(0.1 + 0.2 == 0.3)
print(1 / 3)
```

```output
0.30000000000000004
False
0.3333333333333333
```

A float keeps only about 15 to 17 significant digits. Digits beyond that are lost:

```python
print(0.12345678901234567890)
print(1.0000000000000001 == 1.0)
```

```output
0.12345678901234568
True
```

Integers don't have this problem: whole numbers are always exact. When you compare floats, round them first, for example with `round(x, 2)`:

```python
total = 0.1 + 0.2
print(round(total, 2) == 0.3)
```

```output
True
```

### String literals and quotation marks

A **string** is text in quotes. You can use single quotes `'...'` or double quotes `"..."`; both make the same kind of string. The start and end quote must match:

```python
print('pasta' == "pasta")
```

```output
True
```

Choosing the quote type helps when the text itself contains a quote. Use the other kind on the outside, or put a **backslash** `\` in front of the inner quote. The backslash is an **escape** character: it tells Python "the next character is part of the text":

```python
print("It's sunny")
print('She said "hi"')
print('It\'s raining')
```

```output
It's sunny
She said "hi"
It's raining
```

Other common escapes are `\n` (start a new line) and `\\` (a real backslash).

Triple quotes `"""..."""` or `'''...'''` make a string that can run over several lines:

```python
note = """Buy:
- rice
- beans"""
print(note)
print("Line one\nLine two")
```

```output
Buy:
- rice
- beans
Line one
Line two
```

An empty string, `""` or `''`, is a valid string with no characters in it.

## Common mistakes

**Mismatched quotes.** A string that starts with `"` must end with `"`. Here Python never finds the closing double quote:

```python
city = "Vienna'
```

```error
SyntaxError: unterminated string literal (detected at line 1)
```

**Using the same quote inside the string.** The inner `'` ends the string early:

```python
print('It's late')
```

```error
SyntaxError: unterminated string literal (detected at line 1)
```

**Mixing strings and numbers with `+`.** A number in quotes is text, so Python can't add it to a number:

```python
print("3" + 4)
```

```error
TypeError: can only concatenate str (not "int") to str
```

**Writing `true` or `TRUE`.** Only `True` and `False`, with a capital first letter, are Boolean literals.

**Expecting `0.1 + 0.2 == 0.3` to be `True`.** Float sums can be a tiny bit off. Round before you compare.

## Exam traps

- **Decimal point decides the type.** `7` is an `int`; `7.0`, `7.` and `.7` are all floats.
- **Quotes make a string.** `"7"`, `'True'` and `"3.14"` are all `str`, whatever they look like.
- **`True` and `False` are case-sensitive.** `true`, `TRUE` and `"True"` are not Boolean literals.
- **`/` always gives a float.** `6 / 2` is `3.0`, not `3`.
- **Float accuracy.** `0.1 + 0.2` prints `0.30000000000000004`, and comparing it to `0.3` with `==` gives `False`.
- **Quotes inside strings.** `'It's'` is an error; `"It's"` and `'It\'s'` both work.
- **Commas in numbers.** `1,000` is not one thousand; it is two values, 1 and 0.

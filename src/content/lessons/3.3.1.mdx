## Big idea

A **set** is a collection where every value appears at most once. Add a value that's already there and nothing happens. Think of the stamps in a passport collection: you either have a country's stamp or you don't, and having it twice doesn't count.

```python
visited = {"Spain", "Japan", "Spain", "Peru", "Japan"}
print(len(visited))
print(sorted(visited))
```

```output
3
['Japan', 'Peru', 'Spain']
```

A set also has **no order**. Python may store the items in any order, and it can differ from one run to the next. That's why this lesson prints `sorted(...)`, which turns the set into a sorted list, whenever it shows the contents.

## Walkthrough

### What makes a set a set

Three facts define a set:

- **No duplicates.** Each value is stored once.
- **No order.** There is no first or last item.
- **Only immutable items.** Numbers, strings and tuples can go in a set; lists can't (see Common mistakes). The set itself is mutable: you can add and remove items.

A quick and useful trick: turning a list into a set removes the duplicates.

```python
votes = ["pizza", "tacos", "pizza", "sushi", "tacos", "pizza"]
choices = set(votes)
print(len(votes), len(choices))
print(sorted(choices))
```

```output
6 3
['pizza', 'sushi', 'tacos']
```

### Creating sets

Write a filled set with curly braces. To make an **empty** set you must use `set()`, because `{}` makes an empty **dictionary** instead:

```python
primes = {2, 3, 5, 7}
empty = set()
not_a_set = {}
letters = set("banana")
print(type(primes), len(primes))
print(type(empty), len(empty))
print(type(not_a_set))
print(sorted(letters))
```

```output
<class 'set'> 4
<class 'set'> 0
<class 'dict'>
['a', 'b', 'n']
```

`set(...)` takes any collection and keeps one copy of each item. A string counts as a collection of characters.

### Why there are no indexes

An index means "the item at position 2". Since a set has no positions, asking for one is an error:

```python
toppings = {"cheese", "ham", "olives"}
print(toppings[0])
```

```error
TypeError: 'set' object is not subscriptable
```

"Subscriptable" means "can be used with square brackets". Slicing fails for the same reason. Sets give up order in exchange for very fast membership checks. If you need positions, use `sorted(s)` or `list(s)` to get a list first.

You can still loop over a set with `for`, but don't rely on the order the items come out in. When order matters for output, loop over `sorted(s)`:

```python
toppings = {"olives", "cheese", "ham"}
for t in sorted(toppings):
    print(t)
```

```output
cheese
ham
olives
```

### Adding items: `add()`

`add(x)` puts one item in the set. Adding something already there changes nothing and raises no error:

```python
tags = {"cozy"}
tags.add("rainy")
tags.add("cozy")
print(sorted(tags), len(tags))
```

```output
['cozy', 'rainy'] 2
```

To add several items at once, `update()` takes a collection: `tags.update(["warm", "quiet"])`.

### Removing items: `remove()`, `discard()`, `pop()` and `clear()`

- `remove(x)` deletes `x`, and raises `KeyError` if `x` is missing.
- `discard(x)` deletes `x` if it's there, and quietly does nothing if it isn't.
- `pop()` removes and returns **some** item; since there's no order, you can't predict which.
- `clear()` empties the whole set.

```python
basket = {"apple", "pear", "plum"}
basket.remove("pear")
basket.discard("kiwi")
basket.discard("plum")
print(sorted(basket))
basket.clear()
print(len(basket))
```

```output
['apple']
0
```

### Membership: `in` and `not in`

This is what sets are best at. `x in s` is `True` if `x` is in the set:

```python
allergies = {"peanuts", "shellfish"}
print("peanuts" in allergies)
print("milk" in allergies)
print("milk" not in allergies)
```

```output
True
False
True
```

For a large collection that you check often, a set answers `in` much faster than a list, because it doesn't have to look at every item.

## Common mistakes

**Using `{}` for an empty set.** `{}` is an empty dictionary, which has no `add()` method:

```python
words = {}
words.add("hello")
```

```error
AttributeError: 'dict' object has no attribute 'add'
```

**Removing something that isn't there with `remove()`.** Use `discard()` if the item might be missing:

```python
pets = {"cat", "dog"}
pets.remove("rabbit")
```

```error
KeyError: 'rabbit'
```

**Putting a list inside a set.** Set items must be **hashable**: Python must be able to turn them into a fixed number to file them away, and only immutable values allow that. Use a tuple instead of a list:

```python
coords = {[1, 2], [3, 4]}
```

```error
TypeError: cannot use 'list' as a set element (unhashable type: 'list')
```

**Expecting a particular order.** Printing a set directly can show the items in any order. Never answer an exam question as if a set kept the order you wrote.

## Exam traps

- **Sets are a PCEP-30-03 topic.** They are not on the older PCEP-30-02 exam.
- **`{}` is a dict, `set()` is an empty set.** `type({})` is `dict`. `{1}` is a set.
- **Duplicates vanish.** `len({1, 1, 2})` is `2`. Also `{1, True}` has length 1, because `True == 1` in Python.
- **`remove()` vs. `discard()`.** Only `remove()` raises `KeyError` for a missing item.
- **No indexing or slicing.** Any `s[0]` on a set is a `TypeError`, whatever it contains.
- **`set("abc")` splits into characters**, but `{"abc"}` is a set with one string.

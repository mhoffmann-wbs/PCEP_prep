## Big idea

A **function** is a small program inside your program, with a name. You write its steps once, and from then on you can run all of them just by using the name, like a recipe card you can follow whenever you want pancakes.

```python
def say_hello():
    print("Hello!")
    print("Welcome to the shop.")

say_hello()
say_hello()
```

```output
Hello!
Welcome to the shop.
Hello!
Welcome to the shop.
```

Writing the function is called **defining** it. Running it is called **calling** (or **invoking**) it. Defining a function does not run it; only a call does.

## Walkthrough

### Why use functions?

Functions help you in three ways:

- **Decomposition**: you split a big job into small, named steps, such as `read_prices()`, `add_tax()` and `print_receipt()`. Each piece is easier to understand on its own.
- **Reuse**: you write the code once and call it many times, instead of copying the same lines all over your program.
- **Maintainability**: when something needs to change, you fix it in one place, the function, and every call gets the fix.

Compare printing a divider line by hand three times with calling one function three times. If you later want the line to be longer, the function version needs one change, not three.

### Defining a function with `def`

A definition starts with the **keyword** `def` (short for "define"), then the function's name, a pair of round brackets `()`, and a colon `:`. A keyword is a word that Python reserves for its own grammar.

```python
def show_forecast():
    print("Sunny, 24 degrees")

show_forecast()
```

```output
Sunny, 24 degrees
```

The first line, `def show_forecast():`, is called the **header**. The brackets are needed even when they are empty. In [the lesson on parameters](/learn/4.1.3) you'll put names inside them.

### Valid function names

Function names follow the same rules as variable names:

- They may contain letters, digits and underscores `_`.
- They must **not** start with a digit.
- They must not be a keyword such as `def`, `if`, `for` or `return`.
- Upper and lower case are different: `Greet` and `greet` are two different names.

| Name | Valid? |
|---|---|
| `print_menu` | yes |
| `_helper` | yes |
| `step2` | yes |
| `2nd_step` | no: starts with a digit |
| `make-tea` | no: `-` is not allowed |
| `for` | no: it is a keyword |

By convention, Python programmers write function names in lowercase with underscores between words, like `print_menu`. This style is called **snake_case**.

### The body and indentation

The lines that belong to the function are its **body**. Python knows which lines are in the body because they are **indented**: moved to the right, usually by 4 spaces. The first line that is not indented ends the function.

```python
def pack_bag():
    print("passport")
    print("charger")
print("Ready to go!")

pack_bag()
```

```output
Ready to go!
passport
charger
```

`print("Ready to go!")` is not indented, so it is not part of `pack_bag`. It runs straight away, before the call.

A body must contain at least one statement. If you want an empty function for now, write `pass`, a statement that does nothing:

```python
def plan_holiday():
    pass

plan_holiday()
print("Nothing happened, and that's fine.")
```

```output
Nothing happened, and that's fine.
```

### Calling a function

To call a function, write its name followed by round brackets. Without the brackets nothing runs: you are only mentioning the function, not calling it.

```python
def feed_cat():
    print("Bowl filled")

feed_cat()
feed_cat
print("done")
```

```output
Bowl filled
done
```

The line `feed_cat` on its own is allowed, but it does nothing useful.

A function can also call another function:

```python
def boil_water():
    print("Boiling water")

def make_tea():
    boil_water()
    print("Adding tea bag")

make_tea()
```

```output
Boiling water
Adding tea bag
```

### The order things run in

Python reads a file from top to bottom. When it meets a `def`, it only **remembers** the function; the body does not run yet. The body runs each time a call is reached. After the function finishes, Python continues with the line after the call.

```python
print("1. start")

def water_plants():
    print("3. watering")

print("2. before the call")
water_plants()
print("4. after the call")
```

```output
1. start
2. before the call
3. watering
4. after the call
```

So a function must be defined **before** the line that calls it runs. Calling it too early fails:

```python
order_pizza()

def order_pizza():
    print("Pizza ordered")
```

```error
NameError: name 'order_pizza' is not defined
```

Inside a function body, though, you may call a function that is defined further down the file. That's fine as long as both definitions have been read by the time the outer call actually runs, as `make_tea` showed above.

## Common mistakes

**Forgetting the colon or the indentation.** Both are part of the grammar, so the program fails before it runs:

```python
def show_menu():
print("Soup of the day")
```

```error
IndentationError: expected an indented block after function definition on line 1
```

**Forgetting the brackets in the call.** `show_menu` without `()` does not run the function. Nothing is printed and there is no error, which makes this mistake easy to miss.

**Calling a function before it is defined.** Python has not read the `def` yet, so the name is unknown and you get a `NameError`.

**Using an invalid name.** A name that starts with a digit is a syntax error:

```python
def 3d_print():
    print("printing")
```

```error
SyntaxError: invalid decimal literal
```

## Exam traps

- **Definition does not mean execution.** A `def` prints nothing by itself. Count only the calls when you work out what a program prints, and in the order they happen.
- **Define before you call.** A call above the `def` raises `NameError`. A call inside another function's body is fine as long as everything is defined before that outer function is called.
- **Where the body ends.** The first line that is indented less than the body is no longer part of the function and runs immediately.
- **Name rules.** Watch for names that start with a digit, contain `-` or spaces, or are keywords. Also remember that `Print` and `print` are different names.
- **Name without brackets.** `func` is not the same as `func()`; only the second one runs the body.

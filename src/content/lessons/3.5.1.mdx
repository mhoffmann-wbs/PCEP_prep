## Big idea

A **string** is a piece of text: a word, a sentence, a recipe step, even an empty line. In Python you write a string by putting text between quotation marks:

```python
city = "Lisbon"
print(city)
```

```output
Lisbon
```

The quotes are not part of the text. They only tell Python where the string starts and where it ends. A string is a **sequence** of characters, kept in order, so you can count them, read them one by one and cut pieces out, much like a list.

## Walkthrough

### Single, double and triple quotes

Python accepts three ways to quote a string. Single quotes and double quotes mean exactly the same thing:

```python
a = 'tea'
b = "tea"
print(a == b)
```

```output
True
```

Triple quotes, written as three single quotes `'''` or three double quotes `"""`, also make a string. Their special power is that the string may run over several lines (more on that below).

```python
note = """Buy flour"""
print(note)
```

```output
Buy flour
```

### Escape sequences

Some characters are hard to type inside a string, such as a line break. The **backslash** `\` starts an **escape sequence**: the backslash plus the next character together stand for one special character.

| Escape | Means |
|---|---|
| `\n` | new line |
| `\t` | tab (a wide space) |
| `\\` | one backslash |
| `\'` | a single quote |
| `\"` | a double quote |

```python
print("Monday\nTuesday")
print("Name:\tMia")
print("C:\\recipes")
```

```output
Monday
Tuesday
Name:	Mia
C:\recipes
```

An escape sequence counts as **one** character, even though you typed two:

```python
print(len("\n"), len("a\tb"))
```

```output
1 3
```

### Quotes and apostrophes inside a string

A string ends at the next quote of the same kind that started it. To put an apostrophe inside, either use the other kind of quote around it, or escape it with a backslash:

```python
print("It's raining")
print('She said "hello"')
print('It\'s sunny')
print("The sign says \"Open\"")
```

```output
It's raining
She said "hello"
It's sunny
The sign says "Open"
```

### Multiline strings

A triple-quoted string keeps the line breaks you type inside it:

```python
recipe = """Pancakes:
- 2 eggs
- 1 cup milk"""
print(recipe)
```

```output
Pancakes:
- 2 eggs
- 1 cup milk
```

Each line break you typed becomes a real `\n` character in the string. You can get the same result in a normal string by writing `\n` yourself.

### Indexes: one character at a time

Each character has a position, its **index**. Just like lists, positive indexes start at 0 from the front, and negative indexes start at -1 from the back:

```python
word = "pizza"
print(word[0], word[1], word[-1], word[-2])
```

```output
p i a z
```

| Character | `p` | `i` | `z` | `z` | `a` |
|---|---|---|---|---|---|
| Positive index | 0 | 1 | 2 | 3 | 4 |
| Negative index | -5 | -4 | -3 | -2 | -1 |

Reading one character gives you a new string of length 1. Python has no separate "character" type.

### Slicing: taking a substring

A **substring** is a smaller piece of a string. A **slice** `text[start:stop]` takes the characters from `start` up to, but **not including**, `stop`:

```python
day = "Wednesday"
print(day[0:3])
print(day[:3])
print(day[3:])
print(day[-3:])
```

```output
Wed
Wed
nesday
day
```

Leave out `start` to begin at the front, and leave out `stop` to go to the end. As with lists, a slice past the end does not fail, it just stops early.

### Slice steps

The third number in a slice, the **step**, says how many characters to jump each time. A negative step goes backwards:

```python
letters = "abcdefgh"
print(letters[::2])
print(letters[1:7:3])
print(letters[::-1])
```

```output
aceg
be
hgfedcba
```

`text[::-1]` is a handy way to get a string reversed.

### Strings are immutable

**Immutable** means "cannot be changed". Once a string exists, you can't replace one of its characters. Trying to do so raises an error:

```python
pet = "cat"
pet[0] = "b"
```

```error
TypeError: 'str' object does not support item assignment
```

What you *can* do is build a **new** string and give it the same name:

```python
pet = "cat"
pet = "b" + pet[1:]
print(pet)
```

```output
bat
```

Here `+` glues two strings together. The old `"cat"` was not changed. The name `pet` simply points to the new string `"bat"` now.

### Length with `len()`

`len()` counts the characters in a string. Spaces and punctuation count too:

```python
print(len("rain"))
print(len("rainy day!"))
print(len(""))
```

```output
4
10
0
```

`""` is the **empty string**: a string with no characters at all. The last valid index of any string is `len(text) - 1`.

### Searching with `in` and `not in`

The `in` operator checks whether one string appears inside another. It gives `True` or `False`. `not in` gives the opposite:

```python
forecast = "light rain later"
print("rain" in forecast)
print("snow" in forecast)
print("snow" not in forecast)
print("Rain" in forecast)
```

```output
True
False
True
False
```

The search is **case-sensitive**: an uppercase `R` and a lowercase `r` are different characters.

## Common mistakes

**Reading past the end.** The word `"snow"` has indexes 0 to 3. Index 4 does not exist:

```python
weather = "snow"
print(weather[4])
```

```error
IndexError: string index out of range
```

**Trying to change one character.** Strings are immutable, so `text[0] = "X"` always raises a `TypeError`. Build a new string instead.

**Mixing up the quote types.** `'It's late'` stops at the apostrophe, and the rest of the line confuses Python:

```python
print('It's late')
```

```error
SyntaxError: unterminated string literal (detected at line 1)
```

Use `"It's late"` or `'It\'s late'` instead.

**Counting the backslash.** `"\n"` has length 1, not 2. The backslash and the letter together make one character.

## Exam traps

- **Index vs. slice.** `"abc"[5]` raises `IndexError`, but `"abc"[1:10]` quietly returns `"bc"`.
- **Stop is not included.** `"python"[1:4]` is `"yth"`: three characters, indexes 1, 2 and 3.
- **Escape sequences in `len()`.** Questions count characters in strings like `"a\nb"`, which has length 3, not 4.
- **Immutability.** Any line that assigns to `text[i]` is an error. Look for it hidden inside a loop.
- **Case in `in`.** `"Cat" in "my cat"` is `False`.
- **Negative steps.** With a negative step, start must be to the right of stop, otherwise you get the empty string: `"hello"[0:3:-1]` is `""`.

## Big idea

This topic is only on the older PCEP-30-02 exam; the current PCEP-30-03 exam dropped it.

You already know `else` from `if` statements. Python also lets you put an `else` block after a **loop**. It means: "if the loop finished on its own, without being stopped by `break`, do this as well":

```python
for fruit in ["apple", "pear"]:
    print("Checking", fruit)
else:
    print("All fruit checked")
```

```output
Checking apple
Checking pear
All fruit checked
```

A good way to think of the loop's `else` is "**no break**". It is most useful for searches: the loop looks for something and stops with `break` when it finds it, and the `else` handles the case "not found".

## Walkthrough

### else after a while loop

A `while` loop repeats as long as its condition is true. When the condition becomes false and the loop stops normally, the `else` block runs once:

```python
cups = 3
while cups > 0:
    print("Pouring cup", cups)
    cups -= 1
else:
    print("The teapot is empty")
```

```output
Pouring cup 3
Pouring cup 2
Pouring cup 1
The teapot is empty
```

The `else` lines up with `while`, not with the code inside the loop. If the condition is false from the very start, the body never runs, but the `else` still does:

```python
cups = 0
while cups > 0:
    print("Pouring")
else:
    print("Nothing to pour")
```

```output
Nothing to pour
```

### else after a for loop

A `for` loop works the same way. When it has gone through every item, the `else` runs once. It also runs for an empty list, where the loop body runs zero times:

```python
for day in []:
    print("Planning", day)
else:
    print("No days left to plan")
```

```output
No days left to plan
```

### break skips the else

The **`break`** statement leaves a loop at once. When a loop ends through `break`, Python **skips** its `else` block. This is the whole point of the feature: it tells you whether the loop was stopped early.

Here we search a shelf for a book. The `else` only runs if the search found nothing:

```python
shelf = ["Atlas", "Cookbook", "Dictionary"]
wanted = "Cookbook"
for book in shelf:
    if book == wanted:
        print("Found", book)
        break
else:
    print(wanted, "is not on the shelf")
print("Done")
```

```output
Found Cookbook
Done
```

Change `wanted` to `"Novel"` and the loop goes through every book without breaking, so the `else` runs:

```python
shelf = ["Atlas", "Cookbook", "Dictionary"]
wanted = "Novel"
for book in shelf:
    if book == wanted:
        print("Found", book)
        break
else:
    print(wanted, "is not on the shelf")
print("Done")
```

```output
Novel is not on the shelf
Done
```

`continue` is different from `break`: it only skips to the next round, so it does **not** stop the `else` from running.

```python
for n in [1, 2, 3]:
    if n == 2:
        continue
    print(n)
else:
    print("else ran")
```

```output
1
3
else ran
```

### Tracing loops with else and break

To trace one of these loops, follow it round by round and ask one question at the end: **did a `break` happen?** If yes, skip the `else`. If no, run it.

```python
temperatures = [18, 22, 31, 25]
for t in temperatures:
    print("Reading", t)
    if t > 30:
        print("Heat warning!")
        break
else:
    print("No heat today")
```

```output
Reading 18
Reading 22
Reading 31
Heat warning!
```

The loop never reached 25, and the `else` was skipped because of the `break`.

A `while` loop with `break` works the same way. This one counts guesses and stops at the right answer:

```python
secret = 4
guess = 1
while guess <= 6:
    if guess == secret:
        print("Got it:", guess)
        break
    guess += 1
else:
    print("Out of guesses")
print("Final guess:", guess)
```

```output
Got it: 4
Final guess: 4
```

## Common mistakes

**Thinking `else` runs when the loop body never runs.** It does run then, but that is not the rule. The rule is simply "no `break`". An empty loop has no `break`, so its `else` runs too.

**Thinking `else` runs only when the loop "fails".** It runs every time the loop finishes normally, including the most common case where nothing special happens.

**Indenting the `else` wrongly.** If the `else` is indented to line up with an `if` inside the loop, it belongs to that `if` and runs on every round where the `if` is false:

```python
for item in ["pen", "cup"]:
    if item == "key":
        print("Found key")
        break
    else:
        print("Not", item)
```

```output
Not pen
Not cup
```

**Writing `else` without a matching statement.** An `else` needs an `if`, `while`, `for` or `try` directly above it at the same indentation:

```python
print("hello")
else:
    print("bye")
```

```error
SyntaxError: invalid syntax
```

## Exam traps

- **Loop `else` runs unless `break` happened.** It runs after a normal finish, after zero rounds, and after `continue`.
- **`break` inside a nested loop** only leaves the inner loop, so it skips only the inner loop's `else`. The outer loop and its `else` carry on.
- **Indentation decides ownership.** An `else` lined up with `for` belongs to the loop; lined up with an `if` inside the loop, it belongs to that `if`.
- **Loop variables keep their last value.** After the loop, and in its `else`, the loop variable holds the last value it had, as in `else 3` above.
- **The `else` runs once**, not once per round.

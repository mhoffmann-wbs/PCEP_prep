## Big idea

The `math` module is a toolbox of mathematical functions. You load it with `import math` (see [Import and use modules](/learn/5.2.1)) and then call its functions with dot notation.

For PCEP, four functions matter most:

| Function | What it does | Example | Result |
|---|---|---|---|
| `math.ceil(x)` | rounds **up** to a whole number | `math.ceil(2.1)` | `3` |
| `math.floor(x)` | rounds **down** to a whole number | `math.floor(2.9)` | `2` |
| `math.trunc(x)` | cuts off the decimal part | `math.trunc(2.9)` | `2` |
| `math.sqrt(x)` | square root | `math.sqrt(16)` | `4.0` |

```python
import math
print(math.ceil(2.1), math.floor(2.9), math.trunc(2.9), math.sqrt(16))
```

```output
3 2 2 4.0
```

`ceil` is short for **ceiling** (the top of a room) and `floor` is the bottom, which makes them easy to remember.

## Walkthrough

### Importing and using the `math` module

Import the module once at the top of the program, then call its functions as `math.name(...)`. It also holds useful constants, such as `math.pi`:

```python
import math

radius = 3
area = math.pi * radius ** 2
print(round(area, 1))
```

```output
28.3
```

If you prefer, `from math import ceil, floor, trunc, sqrt` lets you call them without the `math.` prefix.

### Rounding up with `ceil()`

`math.ceil(x)` gives the smallest whole number that is **greater than or equal to** `x`. It returns an `int`.

A typical use: you need whole items to cover a total. Seventeen guests at tables of four need five tables, not 4.25:

```python
import math

guests = 17
tables = math.ceil(guests / 4)
print(tables)
print(math.ceil(5.0), math.ceil(5.01))
```

```output
5
5 6
```

A number that's already whole stays the same. Any fraction at all, however small, pushes it up.

### Rounding down with `floor()`

`math.floor(x)` gives the largest whole number that is **less than or equal to** `x`. It also returns an `int`:

```python
import math

budget = 50
price = 7.5
print(math.floor(budget / price))
print(math.floor(9.99))
```

```output
6
9
```

With a budget of 50 and books at 7.50 each, you can afford 6 books: 6.67 rounds down.

### Removing the fraction with `trunc()`

`math.trunc(x)` simply **chops off** everything after the decimal point. ("Truncate" means to cut short.) It returns an `int`.

For positive numbers, `trunc()` and `floor()` give the same answer. For **negative** numbers they differ, because `floor()` goes **down** (towards minus infinity) while `trunc()` goes **towards zero**:

```python
import math

print(math.trunc(3.7), math.floor(3.7), math.ceil(3.7))
print(math.trunc(-3.7), math.floor(-3.7), math.ceil(-3.7))
```

```output
3 3 4
-3 -4 -3
```

Picture a number line. `-3.7` lies between `-4` and `-3`. Down is `-4`, so `floor()` gives `-4`. Cutting off `.7` leaves `-3`, which is also where `ceil()` lands.

| `x` | `math.floor(x)` | `math.ceil(x)` | `math.trunc(x)` |
|---|---|---|---|
| `2.5` | 2 | 3 | 2 |
| `-2.5` | -3 | -2 | -2 |
| `4.0` | 4 | 4 | 4 |

`math.trunc(x)` does the same as `int(x)` for a float.

### Square roots with `sqrt()`

The **square root** of a number is the value that, multiplied by itself, gives that number. The square root of 25 is 5, because 5 × 5 = 25.

`math.sqrt(x)` always returns a **float**, even when the answer is a whole number:

```python
import math

print(math.sqrt(25))
print(math.sqrt(2))
print(type(math.sqrt(9)))
```

```output
5.0
1.4142135623730951
<class 'float'>
```

A real example: a square garden of 49 square metres has sides of `math.sqrt(49)`, which is `7.0` metres.

The square root of a negative number isn't a real number, so `math.sqrt()` refuses it:

```python
import math
print(math.sqrt(-4))
```

```error
ValueError: expected a nonnegative input, got -4.0
```

### How these differ from `round()` and `//`

The built-in `round()` rounds to the **nearest** whole number, and on an exact half it picks the **even** neighbour. The `//` operator does floor division, so it rounds down like `floor()`:

```python
import math

print(round(2.5), round(3.5), math.ceil(2.5), math.floor(2.5))
print(-7 // 2, math.floor(-7 / 2), math.trunc(-7 / 2))
```

```output
2 4 3 2
-4 -4 -3
```

## Common mistakes

**Forgetting the module prefix.** After `import math`, the function is `math.ceil`, not `ceil`:

```python
import math
print(ceil(4.2))
```

```error
NameError: name 'ceil' is not defined
```

**Thinking `floor()` and `trunc()` are the same.** They agree on positive numbers only. `math.floor(-2.5)` is `-3` but `math.trunc(-2.5)` is `-2`.

**Expecting `sqrt()` to give an `int`.** `math.sqrt(16)` is `4.0`, so `print(math.sqrt(16))` shows `4.0`, not `4`.

**Taking the square root of a negative number.** That raises a `ValueError`, as shown above.

**Passing text.** Values read with `input()` are strings and must be converted first:

```python
import math
print(math.sqrt("9"))
```

```error
TypeError: must be real number, not str
```

## Exam traps

- **This whole section is PCEP-30-03 only.** It's not part of PCEP-30-02.
- **Negative numbers.** `floor()` goes down (`-2.1` becomes `-3`), `ceil()` goes up (`-2.1` becomes `-2`), `trunc()` goes towards zero (`-2.1` becomes `-2`).
- **Return types.** `ceil()`, `floor()` and `trunc()` return an `int`; `sqrt()` always returns a `float`. So `math.sqrt(4) + 1` is `3.0`.
- **Whole numbers.** `math.ceil(5.0)` is `5`, not `6`.
- **`round()` is not `ceil()`.** `round(2.5)` is `2` (round half to even), but `math.ceil(2.5)` is `3`.
- **Import form.** Watch whether the question used `import math` or `from math import ...`, then check whether the calls match.
